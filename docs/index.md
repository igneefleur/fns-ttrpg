# Accueil

Adaptation d'Outward en jeu de rôle sur table. Ce site porte la version **stable** :
ce qu'on y lit est posé et se joue tel quel. Ce qui s'écrit encore vit dans
[la beta](../owd-beta/), où les règles changent sans préavis.

Le jeu commence à peine, et l'essentiel reste à écrire. Les [armes](content/regles/combat/armes.md)
donnent, pour chacune, ce qu'elle inflige, ce qu'elle pare et les attaques qu'elle permet.
