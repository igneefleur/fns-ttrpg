# Accueil

Adaptation d'Outward en jeu de rôle sur table. Ce site porte la version **stable** :
ce qu'on y lit est posé et se joue tel quel. Ce qui s'écrit encore vit dans
[le chantier](../owd-beta/), où les règles changent sans préavis.

Le jeu commence à peine, et l'essentiel reste à écrire. La première règle posée est
celle des [portées](content/regles/combat/portees.md), qui fixe la grille à un mètre
par case et donne la distance de chaque arme.
