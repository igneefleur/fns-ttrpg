# Règles

L'écriture commence. Deux règles y sont posées pour l'instant.

Les [actions et compétences](base/actions.md) donnent la résolution : ce qu'est une
action, comment se fixe la difficulté d'une compétence, et comment se lance le jet.

Les [portées](combat/portees.md) donnent la grille, la mesure d'une allonge, et la
table qui dit à quelle distance chaque arme est chez elle.

Tout le reste est à écrire.
