# Personnage

La fiche de personnage Outward, montée ici même, hors Roll20 et sans compte : ce
qui suit est exactement le code que l'[extension](../extension/index.md) affiche
dans une partie, servi par ce site et non par elle. On peut donc s'en servir
seul, pour préparer un personnage ou simplement regarder ce que donne la fiche.

Une seule différence, et elle est voulue : ici, le personnage vit dans **ce
navigateur** ; dans Roll20, il est enregistré dans le personnage lui-même, donc
partagé avec tous ceux qui le contrôlent.
