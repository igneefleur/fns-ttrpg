## Cette branche

`main` ne porte que le **hub** : la page d'accueil qui laisse choisir le système.
Elle ne contient aucune règle et aucun outil — ils vivent sur les quatre autres
branches, aux mêmes chemins de fichiers mais avec des contenus sans rapport.
C'est `hub/index.html`, un fichier statique sans dépendance, publié à la racine du
site.

Le contenu Hunter × Hunter qui vivait ici auparavant est passé sur `hxh-main`, avec
son historique.
